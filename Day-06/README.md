\## 🔑 Key Learnings



\### 1. Responsive Design

Designing layouts that adapt to different screen sizes

\- Desktop: 3 columns

\- Tablet: 2 columns

\- Mobile: 1 column



\### 2. Media Queries

```css

@media (max-width: 900px) {

&#x20;   /\* Tablet styles \*/

}



@media (max-width: 600px) {

&#x20;   /\* Mobile styles \*/

}
