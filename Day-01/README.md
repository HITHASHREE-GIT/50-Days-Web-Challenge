## 🔑 Key Learnings

### 1. Semantic HTML Tags
Used proper tags instead of generic divs:
- `<header>` for page header
- `<nav>` for navigation
- `<main>` for main content
- `<section>` for content sections
- `<article>` for independent content
- `<footer>` for page footer

### 2. ARIA Roles for Accessibility
Added ARIA roles:
- `role="banner"` for header
- `role="navigation"` for nav
- `role="main"` for main content
- `role="contentinfo"` for footer

### 3. Document Hierarchy
Proper heading structure:
- `<h1>` for page title
- `<h2>` for section titles
- `<h3>` for sub-sections

### 4. CSS Styling (Added)
- Purple color scheme
- Responsive design
- Hover effects

## 🧩 Challenges Faced
**Challenge:** Understanding when to use `<article>` vs `<section>`
- **Solution:** `<section>` groups related content together
- `<article>` is for self-contained, independent content
